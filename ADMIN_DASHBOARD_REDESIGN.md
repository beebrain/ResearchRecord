# Admin Dashboard - Redesign Specification

**วันที่**: 2025-12-05  
**วัตถุประสงค์**: ออกแบบหน้า Admin Dashboard ใหม่เพื่อแสดงสถิติที่เหมาะสมสำหรับ Super Admin และ Faculty Admin

---

## 🎯 **เป้าหมาย**

1. **Super Admin**: เห็นภาพรวมทั้งมหาวิทยาลัย พร้อม Drill-down ไปยังแต่ละคณะ
2. **Faculty Admin**: เห็นข้อมูลเฉพาะคณะที่ดูแล เปรียบเทียบกับคณะอื่น
3. **ข้อมูล Real-time**: แสดงตัวเลขที่อัพเดทและแม่นยำ
4. **Actionable Insights**: แสดงข้อมูลที่สามารถนำไปใช้ตัดสินใจได้

## 🎨 **Design Elements**

### **Color Scheme**
- **Primary**: `#3B82F6` (Blue) - สำหรับข้อมูลหลัก
- **Success**: `#10B981` (Green) - สำหรับแนวโน้มที่ดี
- **Warning**: `#F59E0B` (Orange) - สำหรับคำเตือน
- **Danger**: `#EF4444` (Red) - สำหรับข้อมูลที่ต้องแก้ไข
- **Q1/Q2**: `#8B5CF6` (Purple) - สำหรับผลงาน Q1/Q2
- **TCI Tier 1**: `#EC4899` (Pink) - สำหรับผลงาน TCI Tier 1

### **Icons**
- 📚 = ผลงานวิจัย
- 👥 = นักวิจัย/ผู้แต่ง
- 🏛️ = คณะ
- 📈 = แนวโน้ม/เปรียบเทียบ
- 🌟 = คุณภาพ
- 💰 = งบประมาณ
- ⚠️ = คำเตือน
- ✅ = สำเร็จ

### **Typography**
- **Header**: `font-size: 1.5rem; font-weight: 600;`
- **Card Title**: `font-size: 1.125rem; font-weight: 500;`
- **Stats Number**: `font-size: 2.25rem; font-weight: 700;`
- **Body Text**: `font-size: 0.875rem; font-weight: 400;`

---

## 📱 **Responsive Design**

### **Desktop (≥1024px)**
- Grid: 3 คอลัมน์สำหรับ Stats Cards
- กราฟแสดงเต็มความกว้าง

### **Tablet (768px - 1023px)**
- Grid: 2 คอลัมน์สำหรับ Stats Cards
- กราฟขนาดเล็กลง

### **Mobile (<768px)**
- Grid: 1 คอลัมน์สำหรับ Stats Cards
- กราฟแสดงแบบ scroll ได้

---

## 🔄 **Real-time Updates**

### **Auto Refresh**
- สถิติหลักอัพเดททุก 5 นาที
- กราฟอัพเดททุก 30 นาที
- รายการผลงานล่าสุดอัพเดททันที (WebSocket)

### **Manual Refresh**
- ปุ่ม "รีเฟรช" ที่มุมขวาบน
- แสดงเวลาที่อัพเดทล่าสุด

| **Quality** | สัดส่วนผลงานตามคุณภาพ, เปรียบเทียบกับค่าเฉลี่ยมหาวิทยาลัย |
| **Researchers** | นักวิจัยในคณะ, นักวิจัยที่ยังไม่มีผลงาน |
| **Recent** | ผลงานล่าสุดของคณะ |
